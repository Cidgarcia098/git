Ramas y fusiones en Git

Las ramas permiten trabajar en nuevas funcionalidades o realizar cambios sin
modificar directamente el código estable de la rama principal (`main`). A
continuación, se describe un flujo básico para crear una rama, guardar cambios
y fusionarlos en `main`.

1. Crear y seleccionar una nueva rama

   Crea una rama llamada `feature/mejora-readme` y cámbiate a ella:

       git checkout -b feature/mejora-readme

   Verificación: el nombre de la rama activa, que aparece en la terminal, debe
   cambiar de `main` a `feature/mejora-readme`.

2. Modificar o agregar un archivo

   Edita un archivo existente, como `README.md`, o crea uno nuevo, por ejemplo
   `notas.txt`. Para agregar una línea al README desde la terminal, ejecuta:

       echo "Nivel 2 de Git dominado" >> README.md

   Verificación: ejecuta `git status`. El archivo modificado aparecerá como un
   cambio pendiente de preparar.

3. Preparar y confirmar los cambios

   Agrega los cambios al área de preparación y crea un commit:

       git add .
       git commit -m "feat: actualizar README con avance de nivel 2"

   Verificación: ejecuta `git status`. Si no quedan cambios pendientes, verás
   el mensaje `nothing to commit, working tree clean`.

4. Volver a `main` y fusionar la rama

   Cambia a la rama principal y fusiona en ella los cambios de
   `feature/mejora-readme`:

       git checkout main
       git merge feature/mejora-readme

   Verificación: ejecuta `git log --oneline` para comprobar que el commit
   aparece en el historial de `main`.

5. Sincronizar los cambios con GitHub

   Sube los commits de la rama `main` al repositorio remoto:

       git push origin main

   Verificación: revisa el repositorio en GitHub y confirma que `README.md`
   incluya los cambios realizados.
